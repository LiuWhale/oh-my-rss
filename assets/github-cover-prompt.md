# GitHub Cover Prompt

The source background was generated with GPT Image2 and then composed locally
with exact text using `scripts/make-github-cover.py`.

```text
Create a polished GitHub repository social preview background for an open-source
project called Oh My RSS. Purpose: communicate an RSS-native AI research radar
that turns research feeds into Chinese paper summaries, category feeds, and
monthly trend reports. Asset role: clean raster background for later exact text
overlay, no embedded text. Composition: wide 2:1 landscape, 1280x640 feel,
crisp white/off-white workspace with subtle depth; central visual metaphor of
RSS waves flowing into organized research paper cards, small abstract charts,
and a calm knowledge-radar dashboard. Scientific content to imply: papers, RSS
feeds, AI summarization, trend analytics, self-hosted automation, open-source
tooling. Style: modern open-source developer aesthetic, precise geometry,
restrained color palette with teal, blue, coral, graphite, warm white; high
contrast, premium but not corporate; no clutter. Text policy: no words, no
letters, no numbers, no fake equations, no small text, no watermark. Avoid:
generic glowing AI brain, fake UI screenshots, dense microtext, stock-photo
look, overdecorated gradients, single-hue purple/blue palette. Output:
high-resolution raster suitable for exact title overlay.
```
